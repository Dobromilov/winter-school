# Отчет о проделанной работе: Skip List (День 1)

## Основные этапы и трудности

-   **Начальный этап:** Возникли сложности с переходом от визуального представления структуры данных Skip List к её практической реализации в коде.
-   **Проработка структуры:** После значительных временных затрат была разработана и определена структура `SkipList` и `Node`.
-   **Итерация и операции:** Следующей проблемой стало понимание механики итерации по многоуровневой структуре для выполнения операций.
-   **Прогресс:** К концу дня было достигнуто базовое понимание алгоритмов вставки и поиска.

## Реализованный функционал

На данный момент реализованы ключевые методы:

1.  **`Put(key, value)`** — Добавление нового элемента или обновление значения существующего по ключу.
2.  **`Get(key)`** — Поиск и получение значения по ключу.

Работа над полной реализацией, включая удаление и другие методы, будет продолжена.
